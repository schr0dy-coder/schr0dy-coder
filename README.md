### 🗄️ [`LSM-Tree KV Store`](https://github.com/schr0dy-coder) — Storage Engine in C++

> *"LevelDB from scratch. For the love of systems."*

```
C++ · File I/O · Systems Programming · Data Structures
```

<details>
<summary><b>↳ View details</b></summary>
<br/>

**What it does:**
- Crash-safe key-value storage engine inspired by **LevelDB/RocksDB** using the **Log-Structured Merge Tree** architecture
- In-memory **Skip-List MemTable**, disk-based **SSTables**, **sparse indexing** and **Bloom Filters** for O(1) negative lookups
- **Write-Ahead Log (WAL)** for atomic commits and crash recovery, plus compaction strategies to manage tombstones and disk space

**Architecture highlights:**
```
Write ──► [ WAL ] ──► [ MemTable / Skip-List ]
                              │ (flush when full)
                        [ Level-0 SSTables ]
                              │ (compaction)
                        [ Level-1..N SSTables ]
                              │
Read ◄── [ Bloom Filter ] ◄── [ Sparse Index ]
```

**Key challenges solved:** Designing lock-free concurrent reads · Implementing Bloom filter false-positive tuning · Managing WAL rotation and recovery replays

</details>
